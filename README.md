# ELDORIA — Живое королевство

Небольшая браузерная средневековая фэнтези-стратегия. Проект полностью разделён на файлы и запускается как статический сайт.

## Запуск
Откройте `index.html` локально или опубликуйте репозиторий через GitHub Pages (Settings → Pages → Deploy from a branch → main / root).

## Структура
- `index.html` — интерфейс и разметка.
- `style.css` — адаптивный визуальный стиль.
- `world.js` — карта, типы местности и проверка доступа по дорогам.
- `buildings.js` — здания, цены, рабочие места и производство.
- `game.js` — игровой цикл, жители, строительство, экономика и интерфейс.
- `save.js` — локальное сохранение.

## Текущая версия
- Изометрически стилизованная сетка долины 9×9.
- Строительство дорог, жилья и производственных зданий.
- Жители с домами, рабочими местами, распорядком дня и перемещением по дорожной сети.
- Внутриигровые часы: жители выходят на работу утром и возвращаются домой вечером.
- Цепочка производства: зерно → мука → хлеб.
- Смена месяцев и сезонов, потребление еды и настроение общины.
- Рынок с покупкой и продажей пяти видов ресурсов.
- Динамические цены: дефицит повышает стоимость, избыток снижает её.
- Караваны прибывают раз в несколько месяцев и временно меняют условия торговли.
- Ежемесячные налоги с населения и расходы на содержание построек.
- Этапы развития: посёлок → деревня → город → столица.
- Городские стены и ворота, встроенные в дорожную сеть.
- Ратуша, сторожевые башни и каменный замок с ограничениями по статусу поселения.
- Королевский совет: налоговые указы, содержание дозора и городская стража.
- Казармы для набора стражников, которые усиливают оборону.
- Предупреждения о разбойниках и выбор между обороной города и выплатой выкупа.
- Стены и сторожевые башни усиливают защиту.
- Автосохранение в браузере.

Сохранение находится в localStorage браузера и не синхронизируется между устройствами.
